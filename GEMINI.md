# Travel app instructions

For any travel plan, PRD, itinerary, place-research, map, menu, destination-folder, or travel-record request, read `README.md`, then activate `.gemini/skills/travel-map-builder/SKILL.md` and follow the canonical workflow at `.agents/skills/travel-map-builder/SKILL.md`. For preparation-only research, activate `.gemini/skills/travel-prep-guide/SKILL.md` and create verified `guideItems` for the shared `준비·꿀팁` menu. For UI-only changes, activate `.gemini/skills/travel-ui/SKILL.md` and follow `.agents/skills/travel-ui/SKILL.md`. Preserve the shared place add/edit/delete, visit check, preparation check, LocalStorage, and JSON export/import flow. For research-only work, use the Gemini CLI prompt in the README, open source pages rather than relying on snippets, return `travel-research.v1` JSON without editing the app, preserve uncertainty and source URLs, and do not publish. Use shared `src/travel-ui/` components; keep data in `travel/<destination-slug>/trip.json` and entries in `page/<destination-slug>/index.html`; verify the mobile app; and publish only when the user explicitly asks.
